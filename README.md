# Muhammad Ali Abid — Portfolio Website

A responsive personal portfolio for a BS Artificial Intelligence student at BZU Multan.

## Preview
Open `index.html` in Chrome, Edge, or Firefox. It includes a responsive layout, dark/light theme, animated sections, skills, projects, and contact links.

## Publish with GitHub Pages
1. Sign in to GitHub and create a repository (for a personal site, `ali-abid-ai.github.io` is a suitable name).
2. Upload `index.html`, `README.md`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the live URL to appear in Settings → Pages. This package is prepared to publish, but is not automatically live until uploaded to a hosting provider.
