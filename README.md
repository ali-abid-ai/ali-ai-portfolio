## Run locally

No build tools or API keys are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/ali-abid-ai/ali-ai-portfolio.git
   cd ali-ai-portfolio
   ```
2. Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Personal configuration

- Update the content in `index.html` when your education, projects, or skills change.
- To enable the email button, set `CONTACT_EMAIL` near the top of `script.js` to your professional email address.
- Replace `assets/profile.jpg` with a new optimized profile image if needed.
- The favicon is stored at `assets/favicon.svg`.

## Deployment with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)`, then save.
5. GitHub Pages will publish the site at the live URL above after the deployment finishes.

## Deployment with Vercel

1. Import this GitHub repository into Vercel.
2. Keep the framework preset as **Other**.
3. Leave the build command and output directory empty (the site is static).
4. Deploy.

## Accessibility and performance

- Responsive navigation for small screens.
- Keyboard-visible focus states and a skip link.
- Semantic HTML and descriptive image text.
- Reduced-motion preference support.
